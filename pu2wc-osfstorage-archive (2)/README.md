# 생성형 AI는 무엇을 인용하는가 — 재현 자료

오세정 (2026). 생성형 AI는 무엇을 인용하는가: 소비자 정보탐색의 대행 관점에서 본 한국어 질의 기반 GEO 실측 연구. 『광고학연구』, 37(4). https://doi.org/10.14377/KJA.2026.8.31.7

이 저장소는 위 논문의 수집 응답, 인용 출처 분류 결과, 코드북, 수집·재현 코드를 담고 있습니다. 논문 부록 III에서 공개하기로 한 자료입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `data/responses_984.jsonl` | 수집 응답 984건 (41개 질의 × 문형 2종 × 4개 엔진 × 3회). 질의, 문형, 엔진, 회차, 수집 시각, 답변 본문, 인용 URL |
| `data/classified_citations_final.csv` | 인용 6,964건의 2축 분류 최종본 (게재본 수치의 기준) |
| `codebook/` | 축 1 채널 형식 12유형 규칙, 산업별 공식 도메인 매칭표, 분류 각주 A·B·C |
| `code/collect_paper1.py` | 원문 회차 수집 도구 (공개용 재구성판, 아래 참조) |
| `code/run_wave2_paraphrase.py`, `code/para_queries.py` | 변형 문형 회차 수집 실행기와 변형 질의 목록 |
| `code/reproduce_table2.py` | 분류 최종본에서 논문 표 2와 단계 × 엔진 분포를 다시 계산 |

질의 41개의 원문과 변형 문형, 실사용 증빙은 논문 부록 I(표 I-1)에 있습니다. 축 2(미디어 귀속 5범주) 판정 규칙의 전문은 논문 부록 II에 있습니다.

## 데이터 설명

**responses_984.jsonl**
- `phrasing`: `orig`는 원문 회차(2026-07-13), `para`는 변형 문형 회차(2026-07-16~17)입니다.
- `cited_urls`: 엔진이 반환한 인용 URL 목록이며, 문자열로 직렬화되어 있습니다.

**classified_citations_final.csv**
- `wave`: 원문 또는 변형
- `axis1_기능분류`: 축 1 채널 형식
- `axis2_5범주`: 축 2 미디어 귀속. owned(자사), earned(획득), shared(공유), commerce(중개·거래), etc(미분류). `(제외)`는 해석되지 않은 리다이렉트 18건으로, 분석에서 뺍니다.
- `owned_perquery`: 질의 대상 브랜드 기준의 자사 판정
- `근거유형`: 그 행의 분류가 어느 규칙으로 정해졌는지 표시합니다. 자동 규칙, 미분류 전수 검수, 각주 A·B·C, 공식 소셜 계정 편입 등입니다.

## 분류 절차와 신뢰도

코드북 규칙에 따른 자동 분류를 먼저 적용했습니다. 이어서 잔여 미분류 도메인 333개 전체와 등록 목록 밖의 자사 채널을 연구자가 수동으로 검수했습니다. 공식 소셜 계정 10건은 외부 플랫폼(유튜브, 네이버 블로그, 티스토리) 위에서 질의 대상 브랜드가 직접 운영하는 계정임을 확인한 뒤 자사로 편입했습니다.

분류 타당도는 제2 코더가 확인했습니다. 제2 코더는 실무 경력자이며 연구 가설을 알지 못했습니다. 고빈도 도메인 전량과 꼬리 표본으로 구성한 182개 도메인을 1차 라벨을 가린 상태에서 독립 코딩했고, 결과는 미디어 귀속 α = .98, 채널 형식 α = .96입니다(조정 전 일치도). 경계 사례 처리는 논문 각주 5에 건수와 함께 실려 있습니다.

## 재현

```
cd code
python reproduce_table2.py ../data/classified_citations_final.csv
```

출력은 원문 회차 N' = 3,422 기준으로 자사 456(13.3%), 획득 827(24.2%), 공유 1,525(44.6%), 중개·거래 412(12.0%), 미분류 202(5.9%)입니다. 논문 표 2와 일치합니다.

## 수집 코드에 관하여

수집 스크립트는 논문 수집(2026년 7월) 이후 다른 연구에 재사용되면서 수정되었습니다. `collect_paper1.py`는 그 스크립트에서 두 가지를 바꾼 공개용 재구성판입니다.

1. 모델 식별자를 논문 표 1의 수집 당시 값으로 되돌렸습니다(gpt-5.5, claude-sonnet-5, gemini-3.5-flash, sonar).
2. 수집 이후에 추가된 응답 메타데이터 저장 필드를 제거했습니다.

질의 지시문, 검색 도구 설정, 토큰 상한, 반복 횟수 같은 요청 파라미터와 수집 절차는 수집 당시와 같습니다. 실행하려면 각 엔진의 API 키와 결과를 저장할 Supabase 테이블(`citation_collection`)이 필요하며, 키는 `.env.local`에서 읽습니다. 생성형 엔진의 답변은 시점과 모델 갱신에 따라 달라지므로, 다시 수집하면 같은 응답이 나오지 않습니다. 논문 수치의 재현 기준은 `data/`의 수집 자료입니다.

## 알려진 결함

변형 회차의 v.daum.net 124행은 url 열이 모두 같은 값 하나로 기록되어 있습니다. 이 때문에 변형 회차는 URL 단위 분석을 할 수 없습니다. 도메인 단위 집계에는 영향이 없습니다(논문 부록 III).
